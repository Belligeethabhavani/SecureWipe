🧮 The Math Behind the Proof

Exactly what happens behind the scenes : for the nerds.

1 · What is signed?

SecureWipe signs the entire PDF document (all bytes up to the appended signature block). Any modification — a character in a table, the timestamp, the MAC address, the file hash — changes the SHA-256, invalidating the signature immediately.

bytes_to_sign = PDF_bytes[0 : indexOf("%%SECUREWIPE_V1_SIG_BEGIN%%")] digest = SHA-256( bytes_to_sign ) # 32 bytes signature = Ed25519.sign( digest, private_key ) # 64 bytes

2 · Ed25519 — Edwards-curve Digital Signature Algorithm (RFC 8032)

Ed25519 uses the Twisted Edwards curve −x² + y² = 1 − (121665/121666)x²y² over the prime field 𝔽p where p = 2²⁵⁵ − 19. Security level: 128-bit. Key sizes: 32-byte private, 32-byte public. Signature size: 64 bytes. Fully deterministic — no random nonce at sign time.

Public key: A = [k] · B (k = private scalar, B = base point) Sign(m, k): r = H(k_R ‖ m) R = [r] · B S = (r + H(R ‖ A ‖ m) · k) mod ℓ Signature: (R, S) where ℓ = 2²⁵² + 27742317777372353535851937790883648493 Verify: [8·S]·B == [8]·R + [8·H(R‖A‖m)]·A → ✅ or ❌

3 · Hardware-derived private key (HKDF + DPAPI)

The private key is NOT random — it is deterministically derived from the machine's hardware fingerprint using HKDF-SHA256. The base seed is encrypted with Windows DPAPI (tied to the Windows user account + machine). Even if someone extracts the DPAPI blob, they cannot use it on a different machine.

seed = DPAPI_decrypt( device_seed.enc ) # random, machine-bound hardware = machine_guid | username | mac | sid private_key = HKDF-SHA256( ikm=seed, info="SecureWipe-v1|" + hardware ) public_key = [private_key] · B # visible on the certificate

The public key therefore fingerprints the device. A fresh keypair on a different machine produces a visually different public key.

4 · Attack surface — what's protected and what isn't

✅ Cryptographically sealed

Editing PDF content · Swapping file hashes · Changing timestamps · Modifying device info · Double-marker injection · Cutting signatures between certs

⚠ Requires human trust

Fresh keypair on a new machine (same limitation as PGP/SSH). Mitigated by: device name + MAC + Machine GUID on the cert, and physically verifying the drive is empty.
